# AI Receptionist Plan

Plans an AI receptionist for your business: the call flow, and every piece a real phone line needs, using the free Dograh project as the example.

**Who it is for:** Owners thinking about an AI answering their phones, before anyone installs anything.

**What you need:** Claude Code or Codex and what you know about your calls. The plan itself needs no phone account.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
